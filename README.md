# RAG Sentence Sanitisation

Course research project on lightweight sentence-level sanitisation for indirect prompt injection in RAG passages.

## Project Structure

- `data/` — datasets and processed data
- `src/` — Python source code
- `notebooks/` — Jupyter/Colab notebooks
- `results/` — experiment results
- `figures/` — generated figures
- `literature/` — literature review materials
- `report/` — project report materials

## Environment

The project uses Google Colab as the primary development environment.

## Reproducibility

The project configuration and dependencies are defined in:

- `config.yaml`
- `requirements.txt`
